Handlers

  • onClick — only on Button. A statement or a block of statements.
  • onChange — on TextInput, Select, Slider, Checkbox. Runs after the bound variable is updated.

Language

Keywords: App component fn let state derived if else while for in return import true false

Types: Int, Float, Bool, Str, Array, Any, Null, Unknown

String interpolation: "Hello ${name}" — any expression inside ${...}.

CLI

CommandWhat it does
kara dev [entry]Builds the UI if needed, starts the runtime with hot-reload
kara run [entry]Alias for dev
kara build [entry]Compiles the entry → build/ast.json
kara testRuns the compiler + runtime suites (102 tests)
kara doctorDiagnoses the environment
kara new <name>Creates a project in ./<name>
kara lspStarts the language server (JSON-RPC 2.0 over stdio)
kara versionPrints the KARA version

Config file kara.config.json: entry, outDir, port. Resolved from the nearest project above the entry or the cwd.
