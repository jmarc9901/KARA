Types & type checking

      
Primitives: Int, Float, Bool, Str, plus
      Array and the explicit dynamic escape hatch Any. The language is dynamic
      at runtime, but the compiler runs a static pre-pass with inference:

      

      
      
Arithmetic on incompatible types, mixed-type comparisons, wrong assignment types and wrong
      call arity are all caught before execution.


      
State & derived

      
state holds reactive values; derived computes values from them. The
      compiler orders derived by a dependency graph, so forward references
