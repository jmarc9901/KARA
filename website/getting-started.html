Getting started

From zero to a running reactive UI in about two minutes.

Requirements Install Your first app Hot reload Editor & LSP Desktop (Tauri)

Requirements

Node.js ≥ 20.11 and npm. That's it. The Rust toolchain and Tauri are only needed for the desktop shell (see below).

Install

KARA is distributed as a single npm package that self-prepares its runtime and UI on install:

Your first app

      
Create a project and start the dev server with hot-reload:

      

      
      
Open src/main.kara and make it yours:

      

      
      
Save the file — the app reloads instantly and the window updates. The browser page at
      localhost:5179 is the dev UI; the same program runs inside a native window via
      Tauri later.


      
Hot reload

      
kara dev watches every .kara file in the project (including imported
      modules) and rebuilds on change. Compile errors appear in the browser with
      line/col and a caret into the source; runtime errors show the offending line too.


      
Editor & LSP

      
KARA ships a zero-dependency language server:

      

      
      
The VS Code extension (kara-lang) adds syntax highlighting, live
      diagnostics while you type, type hovers and autocompletion, plus KARA: Run and
      KARA: New project commands.
